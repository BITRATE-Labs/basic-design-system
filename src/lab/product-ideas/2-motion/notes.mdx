# 2. Motion and timing

## Stock

Popups use tw-animate-css at fixed durations: 100ms with `ease` for the dialog, menu and popover, 150ms for the tooltip, and a 200ms `ease-in-out` transition for the sheet. There is no reduced-motion path, so the zoom and slide still play for people who asked for less motion, and the theme swaps instantly.

## Motion tokens (Perkcord)

Three durations (160, 240 and 420ms), a standard ease `cubic-bezier(0.2, 0.8, 0.2, 1)` and an emphasised ease `cubic-bezier(0.22, 1, 0.36, 1)`, an 18px rise and a 70ms delay step, all collapsing to 1ms and 0px under `prefers-reduced-motion`. The `.motion-enter` fade-up and `.motion-delay-N` stagger read them, with a zero-specificity `:where()` reset so nested sections do not inherit their parent's delay. Adopting them means adding the tokens to the scales and a reduced-motion override to the token build, plus one theme rule that points the stock popups' `--tw-duration` and `--tw-ease` at them; the risk is overuse, since staggered fade-ups on every page become noise, so they belong on the first paint of key sections.

## Arrival highlight (Perkcord)

When a URL hash targets an item, it rises 18px from 25% opacity over 520ms while a 22% primary tint fades, using only `:target` and `:has()`. As shipped, the animation's `both` fill holds the final transparent keyframe, so the intended 8% resting tint never shows; the fixed version ends the keyframe on that tint. Adopting it is one utility class; client-side routers that change the hash without a navigation may not re-trigger `:target`.

## Colour-only theme cross-fade (Perkcord)

A class on `<html>` for 220ms around the theme change makes every element transition colour properties only, with no delay and the emphasised ease, so hover and motion transitions are untouched. Reduced motion gets an instant swap instead. Adopting it is about 15 lines of theme CSS and a 30-line `startThemeTransition` helper that product theme toggles call before swapping the class; the universal selector touches every node for 220ms, which needs watching on very large pages.

## Differences from the Perkcord source

- Perkcord's own popups do not animate (its menu is a native popover), so the mapping of tokens to stock popups is this lab's: menu, popover and tooltip fast with the standard ease; dialog base with the emphasised ease; sheet slow with the emphasised ease; every exit one step quicker on the standard ease. The stock keyframe shapes (fade, 95% zoom, 8px slide) are unchanged.
- The theme cross-fade rules are unlayered here, so they drop Perkcord's `!important`; inside `@layer base`, as in Perkcord, they need it.
- `startThemeTransition` drops Perkcord's duration and easing options, which exist to sync with its animated scene.
- `data-motion="reduce"` is new: it forces the reduced-motion collapse, for an in-app setting and for the preview toggle.
- The fixed arrival highlight is the fix the review proposed, not Perkcord code.
